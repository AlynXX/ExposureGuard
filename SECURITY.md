# Security policy

## Supported version

Only the latest commit on `main` is supported while this project is a demo.

## Reporting a vulnerability

Please report security issues privately to the repository owner. Do not include
real breach data, passwords, identity documents or other personal data in a
report. A useful report contains reproduction steps using synthetic fixtures,
the affected browser and the expected versus observed behaviour.

## Threat-model boundaries

The demo is not a breach oracle and does not prove that an account is safe. Its
email flow and breach results are fictional. File processing is intentionally
client-side; adding uploads, persistence or real provider queries requires a new
privacy and abuse review.
